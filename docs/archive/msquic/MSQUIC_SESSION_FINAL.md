### 1. Fixed Build System (5 minutes)

**Issue**: Build was failing with:
```
error: expected function or variable declaration after pub
pub usingnamespace @import("quic_msquic.zig");
```

**Solution**: Replaced `pub usingnamespace` with explicit re-exports in `src/transport/quic.zig`:
```zig
const quic_msquic = @import("quic_msquic.zig");

pub const QuicError = quic_msquic.QuicError;
pub const QuicTransport = quic_msquic.QuicTransport;
pub const QuicConnection = quic_msquic.QuicConnection;
pub const QuicStream = quic_msquic.QuicStream;
pub const QuicClient = quic_msquic.QuicClient;
pub const QuicClientStream = quic_msquic.QuicClientStream;
```

### 2. Fixed Double-Free Bug (20 minutes)

**Issue**: Server was crashing with "Invalid free" error when sending data

**Root Cause**: In `QuicStream.write()`, buffers were tracked before `StreamSend()` was called. If the send failed, the error path would:
1. Manually free the buffer
2. Return, triggering the errdefer
3. errdefer would try to free again → DOUBLE FREE

**Solution**: Only track buffers AFTER successful send:
```zig
// Before fix: Track → Send → Free on error (+ errdefer = double free)
// After fix: Send → Track on success, let errdefer handle failures
```
