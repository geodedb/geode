# Roadmap & Future Plans

Near-term goals:
- Distributed writes & sharded transactions (Raft or 2PC); HA replication
- Full-text search analyzers & BM25; SEARCH functions
- Graph algorithms library (centralities, communities, isomorphism)
- GraphQL interface or translator; HTTP gateway (optional)
- Performance: parallel execution, improved cost model, plan caching
- Tooling: more client libraries (TS/Python), import/export utilities
- Multi-graph & SQL/PGQ compliance; CREATE GRAPH/GRAPH <name>
- DevOps: Helm chart/Operator; rolling upgrades; discovery
- UI: basic browser/visualizations (community-driven)
- Hardening & testing; governance freshness guarantees
