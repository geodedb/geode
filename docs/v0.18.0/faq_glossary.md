# FAQ & Glossary

FAQ:
- Production-ready? Pre‑1.0; robust core; missing multi‑shard writes.
- Differences vs Neo4j/Janus? GQL standard, Zig runtime, strong security/auditing.
- Gremlin/TinkerPop? Not supported; GQL only.
- Size limits? 64‑bit ids; scale via sharding; constrained by RAM/disk.
- Stored procedures? Built-ins only; UDFs not yet.
- License? MIT.
- How to contribute? Fork, add tests/CANARY, PR.

Glossary: GQL, Property Graph, MVCC, Snapshot Isolation, WAL, ARIES, QUIC, RBAC, ABAC, RLS, TDE, Audit Log, CANARY, Digest, Full/Incremental Backup, DLQ, Prometheus, Grafana, LDBC, Cypher.
