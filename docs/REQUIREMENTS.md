# REQUIREMENTS — Geode v0.18.0

This page summarizes conformance targets and system requirements. Counts are derived from docs/status.csv and enforced by CI; this page avoids embedding numbers that can drift.

## Standards & Conformance

- ISO/IEC 39075:2024 (GQL) minimum conformance implemented
- Extensions documented in docs/GQL_CONFORMANCE_PROFILE.md
- Diagnostics policy: ISO status classes/subclasses + policy codes (US001, IllegalOrderKey, etc.)

## Language Surface (required)

- Parser/lexer to AST
- MATCH/OPTIONAL, WHERE, RETURN, ORDER BY, LIMIT/OFFSET, aggregates, set operations
- Legality checks for ORDER keys; pagination policy (US001)

## Engine Contract

- Logical operators: NodeScan, Expand, Filter, Project, Group, Order, Limit
- Physical implementations: IndexScan/CSR, HashJoin, Sort/Top‑K
- Stable ordering for OFFSET pushdown; deterministic path tie‑break

## Transactions & Storage

- MVCC (SI), WAL/ARIES, page LSN, crash recovery
- WAL‑before‑data enforcement; commit flush policy (always/every_n/time_window_ms)
- FSM and on‑page vacuum/defrag; PageCompact physiological WAL

## Security

- QUIC+TLS mandatory
- RLS/ABAC enforcement
- Audit logging: hash‑chained JSONL, periodic Merkle digest, Ed25519 signatures (DIGEST) — default ON
- No secrets in logs; signing keys required at startup (non‑test)

## Distributed & Ops

- Read federation (coordinator/worker)
- S3 backups: full + incremental
- CDC webhook hardening: retries, DLQ, idempotency, metrics
- Metrics (Prometheus), structured logs, basic tracing

## Tooling

- Evidence governance via CANARY annotations; docs/status.csv generated by tools/status_generate.py
- geode‑audit verification CLI for audit chain/digest/signature checks

## Platform & Build

- Zig 0.15.1, Linux x86_64 (glibc)
- Build: `zig build -Drelease-safe`; tests: `zig build test`

## Performance Targets (non‑binding)

- Query: deterministic pagination; distributed Top‑K
- Storage: WAL fsync before page fsync; directory‑level fsync after create/rename
- Audit: append latency ≤ 500 µs/event (excluding fsync)

Refer to docs/GAP_ANALYSIS.md and docs/status.csv for evidence coverage details.
