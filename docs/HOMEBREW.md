# Geode Homebrew Tap

This document describes how to install Geode via Homebrew on macOS and how to maintain the Homebrew tap.

**Tap Repository**: `github.com/geodedb/homebrew-geode`

## Quick Install (Users)

```bash
# Add the tap and install (named 'geodedb' to avoid collision with Apache Geode)
brew tap geodedb/geode
brew install geodedb

# Or install directly without adding tap
brew install geodedb/geode/geodedb
```

> **Note**: The formula is named `geodedb` (not `geode`) to avoid conflicts with
> the Apache Geode formula in homebrew/core. The binary is still called `geode`.

## Usage

After installation, Geode is available via the `geode` command:

```bash
# Check version
geode --version

# Start the server
geode serve --listen 0.0.0.0:3141

# Use the interactive shell
geode shell

# Execute a query
geode query "RETURN 1 + 1 AS result"
```

## Running as a Service

Homebrew can manage Geode as a background service:

```bash
# Start the service
brew services start geodedb

# Stop the service
brew services stop geodedb

# Restart the service
brew services restart geodedb

# Check service status
brew services info geodedb
```

The service runs with these defaults:

- **Listen address**: `0.0.0.0:3141`
- **Data directory**: `/opt/homebrew/var/lib/geode` (Apple Silicon) or `/usr/local/var/lib/geode` (Intel)
- **Log file**: `/opt/homebrew/var/log/geode/geode.log`
- **Error log**: `/opt/homebrew/var/log/geode/geode.error.log`

## Directory Locations

| Purpose      | Path                                 |
| ------------ | ------------------------------------ |
| Binary       | `$(brew --prefix)/bin/geode`         |
| Data         | `$(brew --prefix)/var/lib/geode`     |
| Logs         | `$(brew --prefix)/var/log/geode`     |
| Config       | `$(brew --prefix)/etc/geode`         |
| Certificates | `$(brew --prefix)/etc/geode/certs`   |

## TLS Configuration

For production use, configure TLS certificates:

```bash
# Create certificate directory
mkdir -p $(brew --prefix)/etc/geode/certs

# Copy your certificates
cp server.crt server.key $(brew --prefix)/etc/geode/certs/

# Start with TLS
geode serve --listen 0.0.0.0:3141 \
  --cert $(brew --prefix)/etc/geode/certs/server.crt \
  --key $(brew --prefix)/etc/geode/certs/server.key
```

## Upgrading

```bash
# Update tap and upgrade
brew update
brew upgrade geodedb

# Check installed version
brew info geodedb
```

## Uninstalling

```bash
# Stop service if running
brew services stop geodedb

# Uninstall
brew uninstall geodedb

# Remove tap (optional)
brew untap geodedb/geode

# Clean up data (optional, destructive!)
rm -rf $(brew --prefix)/var/lib/geode
rm -rf $(brew --prefix)/var/log/geode
rm -rf $(brew --prefix)/etc/geode
```

## Maintainer Guide

### Tap Repository Setup

The Homebrew tap is a GitHub repository that contains Homebrew formula files.

#### Initial Setup

1. **Create the GitHub repository**:

   ```
   github.com/geodedb/homebrew-geode
   ```

2. **Initialize the repository**:

   ```bash
   git clone git@github.com:geodedb/homebrew-geode.git
   cd homebrew-geode
   mkdir Formula
   # Create a README.md with installation instructions
   git add .
   git commit -m "Initial tap setup"
   git push origin main
   ```

3. **Create GitHub Personal Access Token**:
   - Go to GitHub > Settings > Developer settings > Personal access tokens > Tokens (classic)
   - Generate new token with `repo` scope
   - Save the token securely

4. **Add token to GitLab CI/CD**:
   - Go to GitLab project > Settings > CI/CD > Variables
   - Add variable:
     - Key: `HOMEBREW_TAP_TOKEN`
     - Value: (your GitHub PAT)
     - Type: Variable
     - Flags: Masked, Protected

### Automatic Formula Updates

GoReleaser automatically updates the formula when you create a release tag:

```bash
# Create and push a release tag
git tag v0.1.4
git push origin v0.1.4
```

The CI/CD pipeline will:

1. Build macOS universal binary (x86_64 + arm64)
2. Create release archive
3. Calculate SHA256 checksum
4. Push updated formula to `github.com/geodedb/homebrew-geode`

### Manual Formula Updates

If you need to update the formula manually:

```bash
# Clone the tap
git clone git@github.com:geodedb/homebrew-geode.git
cd homebrew-geode

# Edit the formula
vim Formula/geodedb.rb

# Test locally
brew install --build-from-source ./Formula/geodedb.rb

# Commit and push
git add Formula/geodedb.rb
git commit -m "Update geodedb to vX.Y.Z"
git push origin main
```

### Formula Template

The formula is auto-generated by GoReleaser. Here's the expected structure:

```ruby
# Named Geodedb to avoid collision with Apache Geode in homebrew/core
class Geodedb < Formula
  desc "ISO/IEC 39075:2024 GQL-compliant property-graph database with QUIC/TLS transport"
  homepage "https://geodedb.com"
  license "Apache-2.0"
  version "X.Y.Z"

  on_macos do
    url "https://gitlab.com/devnw/codepros/geode/geode/-/jobs/artifacts/vX.Y.Z/raw/dist/geode_X.Y.Z_darwin_universal.tar.gz?job=build-release"
    sha256 "..."
  end

  depends_on "openssl@3"

  def install
    bin.install "geode"

    # Create directories
    (var/"lib/geode").mkpath
    (var/"log/geode").mkpath
    (etc/"geode").mkpath
  end

  def caveats
    <<~EOS
      Geode has been installed!

      Note: This is 'geodedb' (GQL graph database), not Apache Geode.

      To start the server:
        geode serve --listen 0.0.0.0:3141

      To use the interactive shell:
        geode shell

      Data directory: #{var}/lib/geode
      Log directory: #{var}/log/geode
      Config directory: #{etc}/geode

      For TLS certificates, place them in #{etc}/geode/certs/

      Documentation: https://gitlab.com/devnw/codepros/geode/geode/-/tree/main/docs
    EOS
  end

  service do
    run [opt_bin/"geode", "serve", "--listen", "0.0.0.0:3141", "--data-dir", var/"lib/geode"]
    keep_alive true
    working_dir var/"lib/geode"
    log_path var/"log/geode/geode.log"
    error_log_path var/"log/geode/geode.error.log"
  end

  test do
    system "#{bin}/geode", "--version"
  end
end
```

### Troubleshooting

#### "Error: No available formula with the name geodedb"

The tap isn't added:

```bash
brew tap geodedb/geode
```

> **Note**: Use `geodedb` (not `geode`) to avoid installing Apache Geode by mistake.

#### "SHA256 mismatch"

The release archive was updated after the formula was created. Re-run the release or manually update the SHA256:

```bash
# Download and calculate SHA256
curl -L "https://gitlab.com/devnw/codepros/geode/geode/-/jobs/artifacts/vX.Y.Z/raw/dist/geode_X.Y.Z_darwin_universal.tar.gz?job=build-release" | shasum -a 256
```

#### Formula not updated after release

Check that:

1. `HOMEBREW_TAP_TOKEN` is set in GitLab CI/CD variables
2. The token has `repo` scope on GitHub
3. The tap repository exists at `github.com/geodedb/homebrew-geode`

Check GoReleaser logs in the CI/CD job for errors.

#### Service won't start

Check logs:

```bash
cat $(brew --prefix)/var/log/geode/geode.error.log
```

Common issues:

- Port 3141 already in use
- Missing data directory permissions
- TLS certificate issues

### CI/CD Configuration

The Homebrew formula is generated by GoReleaser. Relevant configuration in `.goreleaser.yaml`:

```yaml
# macOS-only archive for Homebrew
archives:
  - id: geode-universal-archive
    ids:
      - geode-universal
    name_template: "{{ .ProjectName }}_{{ .Version }}_darwin_universal"

# Homebrew tap configuration
brews:
  # Named 'geodedb' to avoid collision with Apache Geode in homebrew/core
  - name: geodedb
    ids:
      - geode-universal-archive
    repository:
      owner: geodedb
      name: homebrew-geode
      token: "{{ .Env.HOMEBREW_TAP_TOKEN }}"
    # ... rest of configuration
```

### Supported macOS Versions

The universal binary supports:

- macOS 11 (Big Sur) and later
- Intel (x86_64) and Apple Silicon (arm64)

Homebrew itself requires macOS 12 (Monterey) or later for full support.
