## Prompt: Geode v0.17.0 → v0.18 gap‑closing delivery (feature correctness & completeness)

**You are a senior Geode engineer.** Ship the next set of features that close the highest‑impact gaps from v0.17.0 while preserving product‑level correctness and avoiding regressions.

### Ground truth (use only these facts as canonical context)

* **What v0.17.0 delivers today**

  * **Secure transport:** QUIC‑only with TLS; server listens on **8443**; TCP removed; auto‑generates a self‑signed cert if none is provided. End‑to‑end test proves query round‑trip over QUIC/TLS.&#x20;
  * **Clustering:** Raft replication hardened with **snapshots + log compaction**; **dynamic membership (joint consensus)**; validated failover; `cluster_spawn.sh` demo. Cross‑shard transactions via **2PC over Raft**.&#x20;
  * **Query engine:** Complete DML (INSERT/UPDATE/DELETE) with **RLS enforcement + audit logging**; recursive & bounded path queries; ORDER BY enforced for deterministic LIMIT/OFFSET; initial **CBO v1** (disabled by default; enable with `GEODE_ENABLE_CBO=1`).&#x20;
  * **Built‑in analytics:** `shortestPath()` and `pageRank()` now callable in GQL with bounded resources & deterministic results.&#x20;
  * **Quality & governance:** **14 new E2E tests** covering queries, security, QUIC/TLS, Raft, backups, etc.; **status generator + no‑feature‑flags** checks; **0% untested claimed features.**&#x20;

* **What remains (target for v0.18–v0.19)**

  * P0 gaps: **Distributed query federation** (global ORDER BY/LIMIT, merges), **cloud backups (S3)**, **CDC webhook headers & reliability**, **CBO calibration (small‑N)**.&#x20;
  * P1 gaps: **TDE at rest + MFA**, **FTS phrase/highlight**, **multi‑threaded execution** (parallelism & fairness).&#x20;

### Objectives (Must/Should/Next)

**Must (v0.18):**

1. **Distributed Query Federation (read path)**

   * **Model:** Coordinator‑Worker scatter/gather. Coordinator parses, shards execute local fragments, coordinator performs **global merge**, **global ORDER BY**, and **distributed Top‑K** (per‑shard top‑K + final merge for exact results). Preserve ISO determinism (ORDER BY required for paging).&#x20;
   * **Semantics:** Deterministic pagination across shards; DISTINCT/aggregates work globally; error handling when a shard is unavailable; idempotent retry on coordinator.&#x20;
   * **Switches:** Feature‑flag as `GEODE_ENABLE_FEDERATION=1` (default OFF). EXPLAIN shows a **distributed plan tree** with per‑shard ops and a final MERGE node.&#x20;

2. **Backups to S3 (Full + Incremental)**

   * **Mechanics:** Ship **multipart uploads with checksums**; configurable retention; point‑in‑time restore re‑assembles full + incrementals, then WAL. Use Raft snapshot as a consistency anchor.&#x20;
   * **Behavior:** Non‑intrusive (read‑only snapshot), throttled I/O, resumable uploads, integrity verified before finalize. CLI: `geode backup --dest s3://bucket/prefix --mode full|inc`.&#x20;

3. **CDC Webhook Sink Hardening**

   * **Headers:** Allow **custom HTTP headers** (auth tokens, routing).
   * **Reliability:** Retries with exponential backoff + jitter; **idempotency keys**; **DLQ** with metrics for failures; redelivery policy is at‑least‑once.&#x20;

4. **CBO Calibration for Small‑N**

   * **Default remains OFF** (`GEODE_ENABLE_CBO=1` to opt‑in), but add **bias fixes** and guardrails to avoid bad plans for datasets **<100 rows**; richer **EXPLAIN JSON** with estimates; **optimizer decision logging** under a trace flag.&#x20;

**Should (v0.19):**

5. **Security Hardening**

   * **TDE:** AES‑256 for data files + WAL with a key provider interface (allow KMS in future), minimal overhead target **<5%**, integrated with backup/restore.
   * **MFA:** Optional **TOTP‑based MFA** for database logins; admin policy controls.&#x20;

6. **FTS Enhancements**

   * **Phrase queries, proximity, highlighting**; tunable ranking; analyzers pluggable. Keep BM25 compatibility.&#x20;

7. **Multi‑threaded Execution**

   * **Thread‑pool** for operators; intra‑query parallelism where safe; fairness across concurrent sessions; maintain determinism for ordered queries.&#x20;

### Acceptance tests (add to E2E suite; keep zero‑regressions bar)

1. **Federation**

   * **Global ORDER BY + LIMIT** across 3 shards returns stable pagination for 100k rows; page 1 and 2 have no overlap and are repeatable after reshuffle.
   * **Failure path:** Kill one shard → coordinator returns a well‑typed error; retry after recovery succeeds with identical results.&#x20;

2. **S3 Backups**

   * **Full + 3 incrementals** restore to an exact snapshot; checksums verified; WAL replay < 60s for a 10GB dataset on CI hardware.&#x20;

3. **CDC Webhook**

   * Header injection observed at sink; retries backoff as configured; **idempotency** prevents duplicates on forced 502s; failed events land in DLQ with metrics.&#x20;

4. **CBO**

   * For micro‑tables (<100 rows), CBO either matches heuristic plan or outperforms it; **no test** shows a >10% regression in p95 vs heuristic. Toggle test via `GEODE_ENABLE_CBO=1`.&#x20;

5. **Security / FTS / Parallelism (v0.19 targets)**

   * TDE: encrypted pages/WAL on disk; restore works; perf overhead within budget. MFA: login requires second factor when enabled. FTS: a phrase query with highlighting returns expected spans. Parallel: throughput scales \~linearly up to N cores on read‑heavy workload without breaking determinism for ordered queries.&#x20;

> Maintain the **“14 new E2E”** coverage philosophy: every new feature has at least one stable end‑to‑end test plus unit coverage. Keep **0% untested claims** in the status generator.&#x20;
