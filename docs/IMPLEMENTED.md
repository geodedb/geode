- REQ‑GQL‑046 — Transparent data encryption (pages+WAL)
  - Env vars: GEODE_DISK_ENCRYPTION=on, GEODE_DISK_KEY_HEX=<64 hex chars>; optional GEODE_WAL_ENCRYPTION=on
  - Data at rest unreadable without key; WAL payloads encrypted when enabled; page files encrypted when base_path set
  - File permissions: data/WAL files created with mode 0600
  - Key rotation tool: key_rotate (prints export for GEODE_DISK_KEY_HEX); full re-encryption requires offline rewrite (future)
  - Recovery: WAL decrypts on the fly; page manager decrypts on load; checksums computed on plaintext
