# GAP-0894 / GAP-0895 / GAP-0896 Bulk-Seed Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate the single-property bulk-MERGE lock serialization (GAP-0894, Critical), the false-positive per-stream proto_reader stall error (GAP-0895, Medium), and the verbose per-interval metrics log spam (GAP-0896, Low) surfaced by the 14.27M-node divelife bulk seed.

**Architecture:** Three independent fixes.
1. **GAP-0894** — make single-property MERGE insert use the same striped `merge_tuple_locks` table the multi-property path already uses (instead of the graph-global `merge_prop_index_lock` EXCLUSIVE), then prove it scales with a deterministic concurrent-MERGE regression and an end-to-end throughput probe that pins which dispatch path the real client takes.
2. **GAP-0895** — add connection-level liveness to the per-stream stall watchdog so an intentionally-idle multiplexed control stream is not flagged while sibling streams progress; demote it below `error`.
3. **GAP-0896** — emit a compact one-line metrics summary at `info` every tick and gate the full ~100-field dump behind an env flag.

**Tech Stack:** Zig 0.16, `std.Io` mutex/rwlock model, `pooled.ThreadPool`, geode `StorageAdapter` / `ManagedGraph`, named `zig build test-*` steps.

## Triage Summary (read before starting)

Evidence from the divelife run: `mg_rwlock_exclusive_wait_ns_total` climbs 14s→719s+ (faster than wall-clock ⇒ multiple workers simultaneously blocked), `mg_merge_tuple_lock_acquired_total` stays **0**, ~50 nodes/sec, 251% CPU, client zero errors.

Confirmed code facts (file:line):
- The **multi-property** MERGE adapter path `bulkMergeNodeWithReservedIdMultiPropForTenant` (`src/storage/graph_storage_adapter.zig:2444`) serializes only same-tuple writers via the 16384 striped `merge_tuple_locks` (`:2459-2472`), probes under `rwlock` SHARED, and delegates the insert to `bulkInsertNodeWithReservedIdForTenant` (`:2511`) — **no graph-global exclusive lock**.
- The **single-property** MERGE adapter path `bulkMergeNodeWithReservedIdForTenant` (`src/storage/graph_storage_adapter.zig:2318`) instead takes `merge_prop_index_lock` **EXCLUSIVE** graph-globally for every insert (`:2373`) and never touches `merge_tuple_locks` → `mg_merge_tuple_lock_acquired_total` stays 0. This is the documented root cause for the autocommit/fast-path scenario.
- The regular executor holds the **whole-graph EXCLUSIVE write lock** across the full mutation (`src/server/quic_connection_handler.zig:6048-6075`, GAP-0001 rehash-race protection). Both bulk fast-path blocks are gated on `!state.in_txn` AND `!cluster_active` (`:5952`, `:5999`). So a **transactional or cluster-mode** single-prop `MERGE…SET` bypasses the fast path entirely and serializes on `rwlock` EXCLUSIVE — which matches the `rwlock_exclusive_wait` evidence (the fast path takes `rwlock` SHARED, so it cannot produce that signal).
- `group_commit.isEnabled()` defaults **true**; `bulk_ingest.isEnabled()` defaults **false** (opt-in `GEODE_BULK_INGEST`).

**Conclusion:** GAP-0894 has two distinct serialization points depending on the deployment's dispatch path. Task 1–4 below land the definite, low-risk, fully-testable adapter-striping fix (closes the documented autocommit root cause and satisfies the `mg_merge_tuple_lock_acquired_total > 0` acceptance criterion), then the end-to-end probe (Task 5) empirically pins whether the divelife deployment was on the transactional/cluster regular-executor path. Task 6 records that finding so the per-task review can decide whether the (larger, undo-log/Raft-touching) regular-executor change is warranted as a follow-up.

GAP-0895/0896 both live in the watchdog loop at `src/server/main.zig:2693-2749`.

fn napNs(ns: u64) void {
    const req = std.os.linux.timespec{
        .sec = @intCast(ns / std.time.ns_per_s),
        .nsec = @intCast(ns % std.time.ns_per_s),
    };
    var rem: std.os.linux.timespec = undefined;
    _ = std.os.linux.nanosleep(&req, &rem);
}

fn nowNs() u64 {
    var ts: std.posix.timespec = .{ .sec = 0, .nsec = 0 };
    if (comptime @import("builtin").os.tag == .linux) {
        _ = std.os.linux.clock_gettime(.MONOTONIC, &ts);
    } else {
        _ = std.c.clock_gettime(std.c.CLOCK.MONOTONIC, &ts);
    }
    return @as(u64, @intCast(ts.sec)) * std.time.ns_per_s + @as(u64, @intCast(ts.nsec));
}

fn deadlockDeadlineNs(local_secs: u64) u64 {
    const in_ci = std.c.getenv("CI") != null or std.c.getenv("GITLAB_CI") != null;
    const secs: u64 = if (in_ci) 1800 else local_secs;
    return nowNs() + secs * std.time.ns_per_s;
}

const MergeCtx = struct {
    adapter: *adapter_mod.StorageAdapter,
    keys: []const i64,
    ids_out: []u64,
    err: std.atomic.Value(u32) = std.atomic.Value(u32).init(0),
    done: std.atomic.Value(u32) = std.atomic.Value(u32).init(0),
};

fn mergeWorker(ctx_ptr: *anyopaque) void {
    const ctx: *MergeCtx = @ptrCast(@alignCast(ctx_ptr));
    const store = graph_store.getGlobalStore(graph_store.global_allocator());
    const empty = [_]adapter_mod.StorageAdapter.PropKV{};
    for (ctx.keys, ctx.ids_out) |k, *slot| {
        const reserved = store.reserveNodeId();
        const id = ctx.adapter.bulkMergeNodeWithReservedId(
            "g",
            reserved,
            "Taxon",
            "taxon_id",
            .{ .Int = k },
            &empty,
            false, // not apply_on_match
        ) catch {
            ctx.err.store(1, .release);
            ctx.done.store(1, .release);
            return;
        };
        slot.* = id;
    }
    ctx.done.store(1, .release);
}

### Task 2: Fix — stripe single-property MERGE through `merge_tuple_locks`

**Files:**
- Modify: `src/storage/graph_storage_adapter.zig:2318-2412` (`bulkMergeNodeWithReservedIdForTenant`)

- [ ] **Step 1: Replace the function body**

Replace the entire body of `bulkMergeNodeWithReservedIdForTenant` (the function spanning `:2318-2412`, signature unchanged) with the striped version below. It mirrors `bulkMergeNodeWithReservedIdMultiPropForTenant` (`:2444`): acquire the per-tuple stripe (keyed on label + the single merge prop), probe under `rwlock` SHARED, and delegate the insert to the shard-aligned `bulkInsertNodeWithReservedIdForTenant`. The tuple lock provides the same-key atomicity the old `merge_prop_index_lock` EXCLUSIVE used to provide, while disjoint keys run in parallel.

```zig
    // GAP-0891 (RC-1): tenant-threaded variant of bulkMergeNodeWithReservedId.
    pub fn bulkMergeNodeWithReservedIdForTenant(
        self: *StorageAdapter,
        graph_name: []const u8,
        reserved_id: u64,
        label: []const u8,
        merge_key: []const u8,
        merge_value: graph_store.PropertyValue,
        on_create_props: []const PropKV,
        apply_on_match: bool,
        request_tenant: []const u8,
    ) !u64 {
        const mg = try self.getOrCreateGraph(graph_name);
        const store = graph_store.getGlobalStore(graph_store.global_allocator());
        const io = std.Io.Threaded.global_single_threaded.io();

        // GAP-0894: stripe single-property MERGE through the same per-tuple
        // lock table the multi-property path uses, instead of taking the
        // graph-global `merge_prop_index_lock` EXCLUSIVE on every insert.
        // Disjoint (label, merge_key, merge_value) tuples hash to different
        // stripes and proceed in parallel; only same-key MERGE races
        // serialize. The stripe hold spans probe+insert so two writers for
        // the same key cannot both miss-then-insert (no double node).
        const merge_props_1 = [_]PropKV{.{ .key = merge_key, .value = merge_value }};
        const tuple_lock_idx = mergeTupleLockIndex(label, &merge_props_1);
        const tuple_wait_start = monoNanosNow();
        mg.merge_tuple_locks[tuple_lock_idx].lockUncancelable(io);
        const tuple_hold_start = monoNanosNow();
        const tuple_wait_ns = tuple_hold_start -| tuple_wait_start;
        _ = mg.merge_tuple_lock_acquired_total.fetchAdd(1, .monotonic);
        _ = mg.merge_tuple_lock_wait_ns_total.fetchAdd(tuple_wait_ns, .monotonic);
        observeMaxAtomic(&mg.merge_tuple_lock_max_wait_ns_observed, tuple_wait_ns);
        defer {
            const tuple_hold_ns = monoNanosNow() -| tuple_hold_start;
            _ = mg.merge_tuple_lock_hold_ns_total.fetchAdd(tuple_hold_ns, .monotonic);
            observeMaxAtomic(&mg.merge_tuple_lock_max_hold_ns_observed, tuple_hold_ns);
            mg.merge_tuple_locks[tuple_lock_idx].unlock(io);
        }

        // Probe phase under `rwlock` SHARED. `lookupMergeCandidate` reads the
        // merge_prop_index under its own leaf mutex; combined with the
        // per-tuple lock (which serializes same-key writers) this is
        // sufficient — no graph-global exclusive needed.
        {
            const _t_start = monoNanosNow();
            mg.rwlock.lockSharedUncancelable(io);
            _ = mg.rwlock_shared_wait_ns_total.fetchAdd(monoNanosNow() -| _t_start, .monotonic);
            _ = mg.rwlock_shared_acquired_total.fetchAdd(1, .monotonic);
            defer mg.rwlock.unlockShared(io);
            const _hold_start = monoNanosNow();
            defer {
                const _hold_ns = monoNanosNow() -| _hold_start;
                _ = mg.rwlock_shared_hold_ns_total.fetchAdd(_hold_ns, .monotonic);
                _ = mg.rwlock_shared_hold_bulk_merge_ns_total.fetchAdd(_hold_ns, .monotonic);
                const _cur_max = mg.rwlock_shared_max_hold_ns_observed.load(.monotonic);
                if (_hold_ns > _cur_max) {
                    mg.rwlock_shared_max_hold_ns_observed.store(_hold_ns, .monotonic);
                }
            }

            var probe_id: u64 = 0;
            switch (store.lookupMergeCandidate(graph_name, label, merge_key, merge_value, &probe_id)) {
                .found => {
                    if (apply_on_match) {
                        // Bare-SET upsert on the matched node. setNodeProperty
                        // updates the node + merge_prop_index under the store's
                        // own leaf locks; safe under rwlock SHARED + the tuple
                        // lock (which serializes same-key writers). Mirrors the
                        // pre-GAP-0894 apply-on-match branch.
                        try store.setNodeProperty(probe_id, merge_key, merge_value);
                        for (on_create_props) |kv| {
                            if (std.mem.eql(u8, kv.key, merge_key)) continue;
                            try store.setNodeProperty(probe_id, kv.key, kv.value);
                        }
                    }
                    return probe_id;
                },
                .not_indexable => return error.MergeValueNotIndexable,
                .not_found => {},
            }
        }

        // Insert phase: delegate to the shard-aligned bulk insert helper —
        // the same create path the multi-property MERGE uses (:2511). It
        // takes the shard lock for `reserved_id` + rwlock SHARED and updates
        // merge_prop_index under the store leaf mutex. No graph-global
        // exclusive lock anywhere on this path.
        var combined_buf: [64]PropKV = undefined;
        const combined_len = 1 + on_create_props.len;
        const combined_props: []PropKV = if (combined_len <= combined_buf.len)
            combined_buf[0..combined_len]
        else
            try self.allocator.alloc(PropKV, combined_len);
        defer if (combined_len > combined_buf.len) self.allocator.free(combined_props);

        combined_props[0] = .{ .key = merge_key, .value = merge_value };
        if (on_create_props.len > 0) {
            @memcpy(combined_props[1..][0..on_create_props.len], on_create_props);
        }

        const labels_slice = [_][]const u8{label};
        return try self.bulkInsertNodeWithReservedIdForTenant(
            graph_name,
            reserved_id,
            &labels_slice,
            combined_props,
            request_tenant,
        );
    }
```

#!/usr/bin/env bash
# GAP-0894 end-to-end throughput probe.
# Pins which dispatch path concurrent single-prop MERGE takes and confirms
# the striping fix yields parallelism. Run from repo root after `make build`.
set -euo pipefail

BIN="${GEODE_BIN:-./zig-out/bin/geode}"
PORT="${GEODE_PORT:-3141}"
PW="${GEODE_ADMIN_PASSWORD:-probe-pw-change-me}"
DATA="$(mktemp -d)"
CONNS="${CONNS:-8}"
PER="${PER:-2000}"

GEODE_ADMIN_PASSWORD="$PW" "$BIN" serve --listen "127.0.0.1:${PORT}" --data-dir "$DATA" &
SRV=$!
trap 'kill $SRV 2>/dev/null || true; rm -rf "$DATA"' EXIT
sleep 3

DSN="127.0.0.1:${PORT}?insecure=true&user=geode&pass=${PW}"
echo "Driving ${CONNS} concurrent connections x ${PER} single-prop MERGEs (autocommit)..."

for c in $(seq 1 "$CONNS"); do
  (
    base=$(( (c-1) * PER ))
    for i in $(seq 1 "$PER"); do
      id=$(( base + i ))

        "MERGE (n:Taxon {taxon_id: ${id}}) SET n.scientific_name = 'sp${id}', n.rank = 'species'" >/dev/null
    done
  ) &
done
wait
end=$(date +%s%N)
elapsed_ms=$(( (end - start) / 1000000 ))
total=$(( CONNS * PER ))
echo "Inserted ${total} nodes in ${elapsed_ms} ms => $(( total * 1000 / (elapsed_ms+1) )) nodes/sec"

echo "--- key metrics (expect tuple_lock_acquired > 0, exclusive_wait bounded) ---"
"$BIN" query --dsn "$DSN" "RETURN 1" >/dev/null   # warm a connection
# Metrics surface: scrape from the server log / metrics endpoint per your deployment.
echo "Inspect server metrics for mg_merge_tuple_lock_acquired_total (>0 after fix)"
echo "and mg_rwlock_exclusive_wait_ns_total (bounded if autocommit fast-path is used;"

```zig
    /// GAP-0895: connection-aware stall detection. A single idle stream on
    /// an otherwise-live connection (the multiplexed control stream while
    /// bulk mutations flow on sibling streams) is NOT a stall. Group
    /// registered readers by connection — `peer_addr` is the QUIC 4-tuple,
    /// shared by every stream of one connection — and only return a
    /// snapshot when EVERY stream on a connection has been idle past
    /// `threshold_ns` (the whole connection is wedged, the genuinely
    /// actionable condition). Returns the oldest stream of the most-wedged
    /// fully-idle connection, or null if every connection has at least one
    /// stream active within the threshold. O(n^2) in registry size, which
    /// is bounded by the stream-thread cap and only walked at the 5 s
    /// watchdog cadence.
    pub fn connectionLevelStall(self: *Registry, now_ns: u64, threshold_ns: u64) ?StallSnapshot {
        const io = std.Io.Threaded.global_single_threaded.io();
        self.mu.lockUncancelable(io);
        defer self.mu.unlock(io);

        var result: ?StallSnapshot = null;
        for (self.entries.items, 0..) |entry, i| {
            const last = entry.getActivityNs(entry.self);
            if (last == 0) continue; // never recorded activity => not stalled
            const idle = if (now_ns > last) now_ns - last else 0;
            if (idle < threshold_ns) continue; // this stream itself is active

            const peer = entry.getPeerAddr(entry.self);

            // Is ANY sibling on the same connection active within threshold?
            var sibling_active = false;
            for (self.entries.items, 0..) |other, j| {
                if (i == j) continue;
                if (!std.mem.eql(u8, other.getPeerAddr(other.self), peer)) continue;
                const o_last = other.getActivityNs(other.self);
                if (o_last == 0) { // freshly-opened sibling => connection alive
                    sibling_active = true;
                    break;
                }
                const o_idle = if (now_ns > o_last) now_ns - o_last else 0;
                if (o_idle < threshold_ns) {
                    sibling_active = true;
                    break;
                }
            }
            if (sibling_active) continue; // connection is alive — suppress

            if (result == null or idle > result.?.idle_ns) {
                result = .{
                    .idle_ns = idle,
                    .stream_id = entry.getStreamId(entry.self),
                    .peer_addr = peer,
                };
            }
        }
        return result;
    }
```
