GAP-0816 — closed — commit 40e9c2fc — LSP $/cancelRequest handling. Wired into the comptime notification_dispatch table (src/cli/lsp/server.zig) and backed by a bounded CancelRegistry (fixed-capacity 64-slot FIFO ring; integer-vs-string ids disambiguated by a sign-tagged normalized key; structured/malformed ids rejected). handleRequest consults the registry at entry — before the auth gate and dispatch — so a request the client already asked to cancel is answered exactly once with JSON-RPC -32800 (RequestCancelled) and the entry is consumed (a later same-id request answers normally); cancelling an unknown/completed id is a silent no-op (lingers until consumed or FIFO-evicted). GAP-0816 — FOLLOW-UP (reviewer Critical) — cancel-id poisoning fixed. The original CancelRegistry was never cleared when a request was answered, so in this synchronous server — where a `$/cancelRequest` almost always arrives AFTER its target was already answered (the COMMON case) — a late cancel for id N was recorded and then wrongly fired a -32800 against the NEXT request that reused id N (editors recycle small integer ids). Fix: a bounded recently-answered ring (AnsweredRing, same normalizeId key space + FIFO discipline as CancelRegistry). sendResult/sendError AND handleRequest's post-gate point record the answered id and CancelRegistry.clear() any same-id pending cancel (belt-and-braces covering the manual-JSON response paths). handleCancelRequestEntry now consults the answered ring first and SKIPS recording a late cancel (LSP 3.17 §3.17.10 no-op). The full ordering matrix (pre-emptive cancel; answered-then-late-cancel-then-reuse; cancel-serve-dup-cancel-reuse; cancel-for-never-sent; evicted-id residual) is documented in code above handleCancelRequestEntry. Regression: tests/test_gap0816_lsp_cancel.zig adds the poisoning case (answered id → late cancel → reused id answers NORMALLY; proven red→green by disabling the answered-ring check) plus the AnsweredRing pure unit tests and a -32800-echoes-the-cancelled-id assertion; the suite header was corrected to stop overstating coverage (unknown id ≠ already-completed id). test-gap0816 / test-gap0831 / test-lsp / zig build green.
