| 1 | **RLS VM stack OOB write** (H1) | `src/security/rls_core.zig:642-848` | C/I/A | 5 | Med | Cluster-3 | **30** | Stack is `var stack: [64]Value = undefined` on `evaluateCompiledExpression`'s own frame. Every `push_*`/`load_*` performs `stack[sp] = …; sp += 1` with **no bound**. One crafted policy of 65 `push_true` (2 bytes each via `push_const` with any arg; `push_true`=0x02 is 1 byte) overwrites stack-adjacent locals (`pc`, `opcode`, return slot, saved registers) on the same frame of a function running **inside the match-loop auth boundary on every row**. `Value` is a tagged union (mixed `i64`/`f64`/`[]const u8` slice) — attacker controls both tag and 16-byte payload. Corrupting an adjacent row `Value.string` pointer → forged `rls_row` entries or arbitrary-read on next iteration. Corrupting the saved `pc`/`sp` of a re-entering opcode handler → arbitrary-write (WWW) via `stack[sp] = val`. Downstream primitive: **policy-side bypass on all subsequent rows for the session** (I) plus **arbitrary memory write** (A/C). Requires a WRITE path that stores a `CompiledExpression` — today "manually pinned" per GAP-0510, but any admin `CREATE POLICY` path landing on the bytecode compiler weaponises this. Compounding: invalid opcode byte → `@enumFromInt` illegal-value panic = pre-auth RCE-shaped DoS. **CWE-787 / CWE-121 / OWASP A04**. |
| 2 | **RLS raw-string interpreter fallthrough** (M2) | `rls_core.zig:631, 1441-1532` | C/I | 4 | Med | Tenant-2 | **16** | `evaluateExpression` calls `context_evaluator.evaluate(expr.raw, …)` any time `expr.compiled == null`. Interpreter is a hand-rolled precedence parser (`OR` split → `AND` split → paren strip → `(` search). Grammar is recursive but **stateless**: an attacker who can persist a policy's `raw` text (migration tool, test shim, or future `CREATE POLICY` GQL path) gets string-level dispatch inside the auth fast-path — e.g. `has_permission('admin_access') OR current_user() = 'root'`. Args are split on `,` with no quote-awareness, so `has_permission('a,b')` registers two args. `ContextEvaluator.functions` is a `StringHashMap` registered at `init`; no runtime hook, so **no direct RCE**, but: (a) policy logic can be silently re-routed (attacker names arg `admin_access` via quote trimming at `:1487`), (b) evaluator returns `true` on unknown column (`:1583-1584` returns `null` → `false`, but boolean column-ref at `:1524-1532` treats **any non-zero integer/non-empty string as true**). Chain: persist `raw = "1"` policy → bypass deny-by-default. **CWE-94 / OWASP A03**. Fix: reject `raw != null and compiled == null`. |

## Supply-chain & CVE Surface (deferred)

No SBOM/CVE scan in Phase 2 (scanners missing). 24 git-pinned Zig modules in `build.zig.zon` (uri, yaml, toml, strings, repl, vulkan, json, **quic@2ca4f8db**, slog, config, cli, dns, thread-pool, + 11 more security-critical: auth, fle, audit, wal, raft, grpc_zig, protobuf, hnsw, rtree, graph_storage, gql). **QUIC + audit + auth + fle + graph_storage + raft** are the blast radius — a malicious commit to any of these lands on `zig build` next sync. No vendor lockfile signing, no hash-pinning override via public registry. The 3 outstanding Trivy CVEs flagged in brief (2 HIGH, 1 MEDIUM) are on tooling/base image; reachability depends on image contents — **cannot confirm without running `trivy image` on the published container**. Treat as **suspected** until scanned.

## Operational Gaps

- `GEODE_CLUSTER_INSECURE` sets a `log.warn` once at connect time. **Not audit-logged, not alertable, no metric counter, no startup-banner escalation.** An operator rolling a compromised node cannot distinguish safe from insecure from Grafana.
- No TLS/QUIC cryptographic-config review surfaced; QUIC is vendored — assume TLS 1.3 AEAD defaults pending vendor audit.

## Notes

`@enumFromInt(expr.bytecode[pc])` at `rls_core.zig:647` on an out-of-range byte panics in safe builds (illegal-enum-value) — a compiled-policy byte outside `{0x00-0x05, 0x10-0x12, 0x20-0x25, 0x30-0x32, 0x40-0x42, 0xFF}` crashes the auth worker. Additional **fail-closed DoS** primitive, likelihood Low (requires write path). **Confidence: confirmed** for all #1–#12 at static-analysis level; exploitability of #1/#2 is **suspected** pending a live write-path for compiled/raw policies (GAP-0510 parser land).
