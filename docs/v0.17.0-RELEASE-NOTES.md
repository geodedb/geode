# Geode v0.17.0 Release Notes - Feature Completeness

Release Date: 2025-09-25

## Executive Summary

Geode v0.17.0 represents a major feature completeness milestone, closing critical gaps identified in the Feature Correctness & Completeness review. This release delivers production-ready implementations of MATCH/DML operations, cost-based optimization, CDC external sinks, and persistent Raft clustering.

## Major Features

### 1. Complete MATCH Engine
- **Complex Patterns**: Support for arbitrarily complex graph patterns
- **Nested OPTIONAL**: Left outer join semantics preserving nulls
- **Variable-Length Paths**: Filtered expansions with bounded quantifiers (1..n)
- **Cycle Detection**: Automatic detection and prevention of infinite loops
- **Deterministic Execution**: UA005/UA006 tie-break rules for consistent results

### 2. DML Operations
- **INSERT**: Create nodes and edges with property maps
- **UPDATE**: Modify properties with patch semantics
- **DELETE**: Remove entities with cascade support
- **RLS Enforcement**: All DML operations respect row-level security policies
- **Audit Logging**: JSON Lines audit trail with PII redaction

### 3. Cost-Based Optimizer v1
- **Statistics Registry**: Table and column statistics with histograms
- **Cardinality Estimation**: Sophisticated estimation using statistics
- **Join Reordering**: Left-deep enumeration for optimal join order
- **Gated Release**: Enable with `GEODE_ENABLE_CBO=1` environment variable
- **Plan Cache**: Structural key-based caching with <8% collision rate

### 4. CDC External Sinks
- **Kafka Sink**: Native Kafka producer with batching
- **Webhook Sink**: HTTP POST with JSON payloads
- **At-Least-Once Delivery**: Guaranteed delivery with acknowledgments
- **Retry Logic**: Exponential backoff with configurable limits
- **Dead Letter Queue**: Failed messages preserved for analysis
- **Incremental MV Refresh**: CDC-driven materialized view updates

### 5. Raft Persistence & Dynamic Membership
- **Durable Log**: Filesystem-backed with CRC verification
- **Snapshots**: Compressed state snapshots with InstallSnapshot RPC
- **Log Compaction**: Automatic compaction after snapshot creation
- **Dynamic Membership**: Joint consensus for adding/removing nodes
- **Multi-Process Clustering**: Tested with scripts/cluster_spawn.sh
- **2PC over Raft**: Cross-shard transactions with coordinator durability

### 6. Advanced WHERE Clauses
- **Subqueries**: Correlated and uncorrelated subqueries
- **IN Predicate**: Efficient membership testing
- **EXISTS Predicate**: Existence checks with early termination
- **ANY/ALL Quantifiers**: Universal and existential quantification
- **Complex Expressions**: Arbitrary nesting of predicates

### 7. Graph Algorithms
- **shortestPath()**: Dijkstra's algorithm as GQL function
- **pageRank()**: PageRank centrality calculation
- **Resource Bounds**: Memory and time limits for safety
- **Deterministic Results**: Consistent ordering and tie-breaking

### 8. Transport Layer
- **QUIC-Only**: TCP completely removed from codebase
- **Port 8443**: Mandatory QUIC+TLS port
- **Auto-Generated Certs**: Self-signed certificates created if missing
- **No Fallback**: No plaintext or TCP options available

## Breaking Changes

### From v0.16.0
1. **TCP Removed**: No TCP listener or client support
2. **Port Change**: Default port is now 8443 (was variable)
3. **No Feature Flags**: All compile-time flags eliminated
4. **ORDER BY Required**: LIMIT/OFFSET without ORDER BY now errors (US001)

## Migration Guide

### From v0.16.0

1. **Update Port**: Change connection port from any to 8443
2. **Enable CBO** (optional): Set `GEODE_ENABLE_CBO=1`
3. **Configure CDC** (optional): Add Kafka/Webhook sink configuration
4. **Test MATCH**: Verify complex patterns work as expected
5. **Test DML**: Ensure RLS policies are properly configured

### Example Connection

```bash
# Old (v0.16.0)
./zig-out/bin/geodec "RETURN 1" --server 127.0.0.1:7567

# New (v0.17.0)
./zig-out/bin/geodec "RETURN 1" --server 127.0.0.1:8443
```

### Example MATCH Query

```gql
MATCH (p:Person {name: 'Alice'})-[k:KNOWS*1..3]->(f:Person)
WHERE f.age > 25 AND EXISTS {
  MATCH (f)-[:WORKS_AT]->(c:Company)
  WHERE c.name = 'TechCorp'
}
OPTIONAL MATCH (p)-[r:RELATED_TO]->(f)
RETURN p.name, f.name, length(k) AS distance
ORDER BY distance, f.name
LIMIT 10
```

### Example DML

```gql
INSERT (:Person {name: 'Bob', age: 30, email: 'bob@example.com'})

UPDATE (p:Person {name: 'Bob'}) SET p.age = 31

DELETE (p:Person {name: 'Bob'})
```
