# Geode v0.16.0 Release Notes

## Release Date: September 25, 2025

## Overview

Geode v0.16.0 is a **major integration release** that removes all compile-time feature flags and fully integrates all previously experimental features into a unified build. This release represents a significant milestone in system maturity with mandatory security, comprehensive clustering, and production-ready features.

## Key Statistics

- **451 CANARY aspects tracked** (automated evidence system)
- **329 TESTED** (73% coverage with exact output validation)
- **60 BENCHED** (13% with performance variance envelopes)
- **60 IMPLEMENTED** (13% integration complete, tests pending)
- **2 STUB** (<1% - migration CLI commands only)

## Major Changes

### 1. Unified Build System
- **All compile-time feature flags removed**
- Single build command: `zig build -Drelease-safe`
- All features integrated and enabled by default
- No conditional compilation

### 2. Mandatory Security
- **QUIC+TLS only** - TCP support completely removed
- Default port changed from 7567 to **8443**
- Self-signed certificates auto-generated if missing
- Private keys secured with 0600 permissions

### 3. Full System Integration
- **Recursion**: WITH RECURSIVE enabled by default
- **Bounded expansions**: Default ON with max depth 10
- **Phantom prevention**: RangeTracker enabled by default
- **RLS/ABAC**: Row-level security enforced via planner rewrite
- **Materialized views**: Complete and incremental refresh
- **Backup/restore**: CRC-32 verification for integrity

### 4. Production Features
- **Full Raft consensus**: Leader election, replication, automatic failover
- **Audit logging**: JSON Lines with PII redaction
- **ISO compliance**: ORDER BY required with LIMIT/OFFSET
- **Status tracking**: Auto-generated from CANARY annotations

## Breaking Changes

### Transport Layer
```diff
- TCP support removed entirely
- Default port: 7567 → 8443
- Connection: tcp://localhost:7567 → quic://localhost:8443
- No --no-quic or --allow-insecure options
```

### Build System
```diff
- zig build -Dfeature-rls=true -Dfeature-mv=true
+ zig build -Drelease-safe
```

### Query Behavior
```diff
- RETURN x LIMIT 10  # Previously allowed
+ RETURN x ORDER BY x LIMIT 10  # ORDER BY now required
```

## Migration Guide

### From v0.15.0

1. **Update connection strings**:
   ```bash
   # Old
   geodec --host localhost --port 7567
   
   # New
   geodec --host localhost --port 8443
   ```

2. **Remove feature flags from build scripts**:
   ```bash
   find . -name "*.sh" -exec sed -i 's/-Dfeature-[^ ]*//g' {} \;
   ```

3. **Update queries for ISO compliance**:
   ```sql
   -- Add ORDER BY to queries with LIMIT/OFFSET
   RETURN x ORDER BY x LIMIT 10
   ```

4. **Certificate handling**:
   - Place in `certs/server.crt` and `certs/server.key`
   - Or let system auto-generate self-signed certificates
