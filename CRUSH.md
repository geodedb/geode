# CRUSH.md — Geode Dev Quickref (v0.16.0)

- Build
  - zig build -Drelease-safe
  - zig build test -Drelease-safe
  - zig test tests/path.zig
  - zig test tests/path.zig --test-filter "TestName"
- Lint/format
  - zig fmt --check src/ tests/
  - zig fmt src/ tests/
- Repo checks
  - python3 tools/no_feature_flags_check.py --repo .
  - python3 tools/status_generate.py --repo . --out docs/status.csv
  - sh scripts/cluster_spawn.sh
- Style (Zig 0.15.1)
  - Format via zig fmt; no compile-time feature flags; config via env only
  - Imports: use @import; keep minimal; sort logically; no unused imports
  - Naming: types/enums/structs TitleCase; funcs/locals lowerCamelCase; files snake_case.zig
  - Types: prefer explicit types; slices over pointers; optionals only when required
  - Errors: use error sets/unions; return with try/errdefer; no panic; surface ISO GQLSTATUS codes; never log secrets
  - Concurrency/state: avoid globals; use std primitives; deterministic behavior
  - Logging: JSON Lines; INFO normal, ERROR failures; exclude sensitive data
  - Testing: fixed seeds; ≤512MiB RSS; ≤30s per E2E; prefer --test-filter for single cases
- Protocol/runtime
  - QUIC+TLS only; certs auto-created in certs/ (0600 perms)
  - Generated artifacts: docs/status.csv only via status_generate.py (never hand-edit)
- Copilot rules
  - See .github/copilot-instructions.md; honor US001/IllegalOrderKey, bounded quantifiers, Flagger, no OFFSET pushdown without stable order
